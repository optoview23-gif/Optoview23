# Glossário — Optometria Comportamental PT-BR

Referência rápida de termos clínicos na nomenclatura correta para uso em conteúdo.

---

## Nomenclatura de Área

| Termo correto | Evitar | Contexto de uso |
|---|---|---|
| **Optometria Comportamental** | Optometria Funcional | Identificação da abordagem |
| **Terapia Visual (TV)** | VT, Ortóptica (quando inadequado) | Intervenção clínica |
| **Disfunção Visual** | Erro visual, problema de vista | Diagnóstico funcional |
| **Processamento Visual** | Visão perceptual (genérico) | Habilidades cognitivas visuais |

---

## Condições Clínicas

| Termo PT-BR | Inglês | Definição breve |
|---|---|---|
| **Ambliopia** | Amblyopia / Lazy eye | Redução de AV não explicada por patologia ocular |
| **Estrabismo convergente** | Esotropia / Cross-eyed | Desvio ocular para dentro |
| **Estrabismo divergente** | Exotropia / Wall-eyed | Desvio ocular para fora |
| **Convergência Insuficiente** | Convergence Insufficiency (CI) | Dificuldade de manter fusão na visão de perto |
| **Excesso de Acomodação** | Accommodative Excess | Espasmo acomodativo, hipermetropia latente |
| **Insuficiência de Acomodação** | Accommodative Insufficiency | Amplitude reduzida para a idade |
| **Supressão** | Suppression | Inibição cortical da imagem de um olho |
| **Diplopia** | Diplopia / Double vision | Visão dupla |
| **Fixação Excêntrica** | Eccentric Fixation | Fixação fora da fóvea no olho amblíope |
| **Fenômeno de Crowding** | Crowding | Pior AV em contexto visual (letras cercadas) que isolada |

---

## Testes e Avaliações

| Sigla / Nome PT-BR | Inglês | O que avalia |
|---|---|---|
| **AV** | VA (Visual Acuity) | Acuidade visual |
| **PPC** | NPC (Near Point of Convergence) | Ponto próximo de convergência |
| **PPAc** | NPA (Near Point of Accommodation) | Amplitude acomodativa |
| **Cobertura Alternada** | Alternate Cover Test | Foria / tropia latente e manifesta |
| **Cover Test Unilateral** | Unilateral Cover Test | Tropia manifesta |
| **Estereopsia** | Stereopsis / Stereoacuity | Visão de profundidade binocular |
| **Worth 4 Luzes** | Worth 4-Dot Test | Supressão e fusão sensorial |
| **MEM** | MEM Retinoscopy (Monocular Estimation Method) | Lag acomodativo |
| **Flipper ±2,00 D** | Lens Rock / Flipper | Flexibilidade acomodativa |
| **Visuoscopia** | Visuoscopy | Avaliação da fixação (central/excêntrica) |
| **TVD** | Divergence Training | Treino de Vergência Divergente |
| **TVC** | Convergence Training | Treino de Vergência Convergente |
| **AF** | Accommodative Facility | Flexibilidade acomodativa (ciclos/min) |

## Normas de Referência por Idade (Press / Scheiman & Wick)

| Teste | Norma adulto | Norma criança (8–12a) |
|---|---|---|
| PPC — Ruptura | ≤ 5 cm | ≤ 6 cm |
| PPC — Recuperação | ≤ 7 cm | ≤ 8 cm |
| Estereopsia (Titmus) | ≤ 40" arco | ≤ 40" arco |
| AF (monocular) | ≥ 11 cpm | ≥ 7 cpm |
| AF (binocular) | ≥ 8 cpm | ≥ 5 cpm |
| Amplitude acomodativa | Hofstetter: 18,5 – (0,3 × idade) | — |
| VFP (blur / ruptura / recuperação) | 9/19/10 Δ | 9/19/10 Δ |
| VFN (blur / ruptura / recuperação) | 13/21/13 Δ | 13/21/13 Δ |
